# Histopath branding

- `logo.svg`: editable vector lockup; white backing keeps it legible in light and dark README themes.
- `logo.png`: 1280 × 784 raster export of the same lockup.
- `icon.svg`: transparent, text-free symbol; use at 48 px or larger.

Four simplified microscopy tiles in navy and magenta, with focus brackets around one tile.

Colors: navy `#102C50`; accent `#91288F`.

The wordmark uses outlined DejaVu Sans Bold glyphs so no installed font is required to display it. Its original font notice is retained in `FONT-NOTICE.txt`; it applies to the typeface only. Shapes and outlines remain editable in a vector editor.

Histopath is a display name for `histopath-cancer-detection`. The abstract tiles are illustrative branding, not specimen images or a diagnostic claim.

AI-assisted refinement of the approved project logo concept. This asset addition does not introduce or change repository licensing.
